# 问长生 —— 桌面常驻挂机修仙小窗

> 桌面右下角常驻的修仙挂机小窗：打坐吐纳、突破渡劫、宗门坊市秘境灵兽，一窗全收。
> 当前版本 **v5.6.0（阶段五 M1：试炼塔扩容 · CDP 口径 · 弟子线 · 兽潮与大比）**。

## 本次修订（v5.6.0）

- **弟子线（新玩法 · 宗门册最下方「门下弟子」）**：
  - **收徒**：金丹期且晋**真传**后开启。**观礼**免费（每 3 游戏天一次 ≈ 现实 3 分钟）；**相看**花 200 宗门贡献，
    但该弟子的成长与产出系数同时 **+10%**；连抽不出好资质有**保底**（5 次后概率漂移、封顶 ×3）。
    名额随境界与职级涨：金丹+真传 1 → 化神+首座 5 → 大乘+掌门 9。
  - **培养**：**传功**花灵气让弟子进一级（1 → 9 级），代价随等级升、随资质与悟性降。
  - **职权**：**作坊帮工**（出材料 + 贡献）· **派遣任务**（出灵石 + 贡献）；**特长对口再 +30%**。
  - 弟子产出有**硬顶**（合计 2.0 当量 h/日），不会喧宾夺主；材料与贡献直接入账，**不发境界**。
- **兽潮与灵兽大比（新玩法 · 灵兽册底部两区）**：
  - **兽潮抵御**：每 150 游戏天（≈2.5 现实小时）来犯一轮，**三波一并结算**，按抵御表现定档，
    给灵石 + 妖丹，**有掉蛋保底**。不点就不结算，空过记「失守」但不罚。
  - **灵兽大比**：每 210 游戏天（≈3.5 小时）一届，**编队评分**上场，16 强镜像定名次，**领名次赏格**。
- **试炼塔扩到 100 层**：原 60 层上限 → **100 层**，新增 70 / 80 / 90 / 100 四档里程碑
  （外观「凌云客 / 摘星客 / 踏虚客 / 登天客」+ 秘境积分）。⚠ 满级基准战力下**可达约第 71 层**，
  72~100 层是**长线目标**（靠功法 / 灵兽乘区逐步逼近）。
- **修复**：成就册脚注文案写死「90 个」与实际 94 条自相矛盾（已改为按实际条数显示）。
- **测试**：三套 CDP 真机段（烟测 / V2.5 / V2.10）**实跑 108/0 全绿**，销掉自 V4.7 起的积压账。

## 安装

两种产物（`release/` 目录，由 `npm run dist` 打出）：

- **安装版（NSIS）**：`WenChangSheng-Setup-4.0.0-x64.exe` —— 双击安装，可选安装目录，
  自动创建桌面 / 开始菜单快捷方式（快捷方式名「问长生」）。
- **便携版（Portable）**：`WenChangSheng-Portable-4.0.0-x64.exe` —— 单文件免安装，双击即用。

> ⚠ `release/` 里的实包仍是 **4.0.0**（V4 整合版）打的；此后（4.1.0 / 5.1.0 / **5.6.0**）只更新了源码与运行产物
> （`dist/` + `dist-electron/`），要出 5.6.0 安装包需重跑 `npm run dist`（须先 `npm run build`）。

## 数据与存档位置（升级不丢档）

存档固定写在**用户数据目录**（userData），与程序安装位置无关：

```
%APPDATA%\问长生\
├── save.json            主存档（唯一真源；原子写 + 校验和）
├── save.bak ~ save.bak.5 环形备份（约 10 分钟一格，最远 ~50 分钟前）
├── window-bounds.json   窗口位置记忆
└── …
```

- **升级安装 / 覆盖安装都不丢档**：旧档启动时自动补齐新字段（无需手动迁移）；
  存档由旧版本写入的，会盖上新版本号。
- **卸载也保留存档**（未勾选「删除用户数据」时）；重装后进度原样回来。
- 设置面板 →「存档」页可导出 / 导入 JSON 备份，坏档可从环形备份逐格恢复。

## 基本操作

- **关闭按钮（×）**：不是退出——是**藏进托盘**，游戏继续跑；托盘双击唤回。
- **托盘菜单**：显示 / 隐藏小窗、回到右下角、显示存档文件夹、窗口三态（置顶 /
  鼠标穿透 / 锁定位置）、开机自启、退出。托盘悬停可看当前**境界 + 产出/秒**。
- **全局快捷键**：`Ctrl+Alt+Q` 切换鼠标穿透（穿透后窗口"看得到、点不到"，这是紧急出口）。
- **窗口**：无边框透明，顶栏可拖拽、可缩放；下次启动回到上次位置；
  拔掉显示器 / 改分辨率 / 改缩放后会自动夹回可见工作区。

## 性能与省电

- 窗口藏进托盘后**计时照跑**（后台不节流），DOM 刷新自动降到 5 秒一拍；
- 窗口可见但 2 分钟无人操作，画面自动降到 2 秒一拍省电（挂机产出分毫不变）；
- 氛围系统帧率不足时自动降载（粒子减稀 → 停天气，恢复后升回）。

## 故障排查

- **窗口发黑（透明失效）**：个别显卡 / 驱动下透明窗口会发黑，给启动参数加 `--no-gpu`
  可禁用硬件加速兜底。
- **托盘图标空白**：确认 `assets/tray.png` 存在（由 `python scripts/gen_icon.py` 生成）。
- **重复启动**：已内置单实例锁，重复启动只会唤起已有小窗。

## 开发

```cmd
npm install          安装依赖
npm run dev          开发模式（HMR）
npm run build        构建渲染层 dist/ + 主进程 dist-electron/
npm start            启动实机窗口（等价 scripts\launch.cmd）
npm run dist         打安装包（先 build 再 electron-builder）
node tests\wcs_regress.mjs   全量回归（≈2 秒：自动择优解释器 + 并发；见下）
```

回归运行器（`tests\wcs_regress.mjs`）常用开关：`--only V4.7` 只跑名字含该关键字的份数、
`--jobs N` 并发数（默认 min(8, CPU)）、`--serial` 串行排查、`--list` 只列清单；
解释器默认自动择优（真 Node ≥22.7 免 flag → 真 Node <22.7 带 `--experimental-detect-module`
→ Electron 充当 node），也可用 `WL_NODE=<node.exe 路径>` 指定。PowerShell 一把梭：
`powershell -File tests\run_regress.ps1`（参数原样透传）。

代码版本 `package.json` 与 `src/systems/SaveSystem.js` 的 `APP_VERSION` 两处同步。
