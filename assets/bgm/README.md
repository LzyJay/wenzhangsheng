# assets/bgm —— 音乐素材目录（默认留空）

本目录**不在仓库中附带任何音频文件**。原始素材为第三方商业唱片（麦振鸿《仙剑奇侠传》原声），
版权不属于本项目，故在开源发布时已从仓库与全部提交历史中移除。

## 自行提供音乐

1. 准备 `.mp3` 文件（任意文件名，支持中文）；
2. 放入本目录，形如 `assets/bgm/你的音乐.mp3`；
3. `npm run dev` 或重新 `npm run build` 后生效（构建时由
   `import.meta.glob('../assets/bgm/*.mp3')` 静态收集）。

## 没有音乐时

程序**不会崩溃**：启动后在日志里提示「BGM 素材缺失（assets/bgm 为空）」，
其余玩法、音效、存档全部正常。设置面板的音量滑杆此时对 BGM 无效。

## 注意

- 只把你有权使用的音频放进本目录；再提交前请确认 `.gitignore` 已忽略
  `assets/bgm/*.mp3`（默认已忽略）。
- 若确需随仓库分发，请改用自有版权或 CC0 / CC-BY 素材，并在 README 注明来源与许可。
