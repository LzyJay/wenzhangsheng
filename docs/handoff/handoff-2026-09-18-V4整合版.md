## 三、铁律（违反即返工，历史教训都在开发册 §九 / §十四）

1. **`realms.js` 是生成物禁止手改**——改数值只改 `data-source/72级数值表.csv` 后重跑 `npm run gen:values`；对账 `node scripts/audit_values.mjs`（已入回归）。
2. **存档真源** `%APPDATA%\问长生\save.json`——**主人的档绝对不许动**；测试要写盘时 stub `window.__wcs.save.save` 全链路阻断。
3. **一次一模块、对外串行验收**；System 之间禁止互相 import；装配层 `main.js` 是唯一同时碰 DOM 与 systems 的地方。
4. **文档四件套随码走**：模块表/认领表、交付笔记、验证一览、版本日志，缺一不可（开发册 §十 第 4 条）。
5. **交付必可运行**：改 → 全量回归 → `vite build` → **`scripts\launch.cmd` 启动实机窗口**。只给"改了哪些文件"不算交付。
6. **打包 exe 只在主人明说时做**（`npm run dist`；builder 不会自动重建 dist，**必须先 build**）。
7. 数据先行；不改既有数值口径；补自测并跑全量回归；版本号两处同步（自测里有版本钉断言，升版要一起改，当前钉 4.0.0 的共 10 份：9 份 V3.5.x 自测 + V4.5）。

## 四、环境坑（本机 Windows / WorkBuddy 环境实测）

1. **node 不在 PATH**。用 node20 全路径：
   `%USERPROFILE%\.workbuddy\binaries\node\versions\20.18.0.installing.18348.__extract_temp__\node-v20.18.0-win-x64\node.exe`
2. **逻辑自测**（src/*.js 是 ESM）用 electron 充当 node：`$env:ELECTRON_RUN_AS_NODE='1'; node_modules\electron\dist\electron.exe --experimental-detect-module tests\wcs_regress.mjs`（regress 内部 spawn 会自动带该 flag）。
3. **vite build 必须用 node 20**（node 22 曾崩 html-proxy）；build 输出会被 IDE 工具当 watch 吞掉——**用 dist mtime 验证落盘**，别信终端输出。
4. **PowerShell 外层吞 `$` 变量**：复杂命令写成 .ps1 用 `powershell -File`；cmd 里 `&` 调 powershell 要分两步。无 bash。
5. **CDP 真机测试**（node22 或 electron 充当，需全局 WebSocket）：`scripts\launch-debug.cmd` 起 9229 → `node tests\V2整合版-CDP烟测.mjs` 等。启动前**先 `Get-Process electron` 查旧实例**——单实例锁会把新启动并进旧进程，窗口还是旧代码；先 `Stop-Process` 本项目路径的 electron 再起。
6. **launch.cmd** 已内置：清 `ELECTRON_RUN_AS_NODE`（否则秒崩）+ `start` 脱离作业对象。
7. **electron-builder 24.13.3 两个坑**（V4.5 实测）：`build.win.companyName` / `legalCopyright` 非法会被 schema 拒——版本信息走**顶层 `copyright`**（LegalCopyright）+ `author`（CompanyName）；CLI **只能 `--win`**（`--win x64` 报 Unknown target，arch 在配置里）。本次已绕过，别再往回改。
8. **PowerShell `Get-Content -Raw` 读 UTF-8 后 `.Contains('中文')` 会编码误报 False**——判定 bundle 内容用 `Select-String`。
9. 系统 prefers-reduced-motion = true；动效断言按降级口径。electron 子进程回归偶发「无汇总行」崩溃 / `V3.5.9` autoBrewFor 偶发（成丹随机 0.3^N 连败）——单独重跑即绿，属已知 flaky。
10. 全局快捷键 Ctrl+Alt+Q（穿透出口）注册在主进程；测试穿透相关别抢这个组合键。
