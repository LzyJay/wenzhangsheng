窗口置顶
鼠标穿透
穿透后整窗不再接收点击（"看得到、点不到"），顶部热区与快捷键 Ctrl+Alt+Q 可随时恢复。
锁定位置
锁定后拖动面板与打坐区不再移动窗口，避免误拖。
开机自启
随系统登录自动启动问长生（藏在托盘，游戏照跑）。仅桌面端生效——浏览器里打开时此开关无效。
动效系统·标准
面板转场 · 数值滚动 · 按钮按压。默认全开——即便系统开着「减弱动态」也照播（否则本机等于没有动效）；想彻底安静就切「静态」，「自动」则跟系统走。
自动突破
修为够了自动冲关（含 ×3 / ×6 小瓶颈，缺破境丹会自动开炉）。渡劫不自动——引雷要你亲自按。
自动寻蛋
灵鹰空闲即自动入万兽林，回来自动收蛋入笼（孵化与破壳仍由你决定）。
自动孵化
有待孵的蛋、且孵化位（金丹起 2 位）有空时自动入孵，孵满即自动破壳收兽（灵兽园满 / 孵位满时自动停下等你腾位）。
丹房自动炼制
开启后每种丹常备 1 枚：库存见底就自动开炉补上（材料不足则等有料再补）。突破 / 渡劫缺丹仍会自动开炉一次，与此开关无关。丹房面板里也有同一个开关。
浮层透明度
丹方 / 宗门 / 纪事这些面板是盖在修行日志之上的；调低底色不透明度即可边开炉边看日志（背景模糊同步减弱，否则字仍被糊掉）。点按循环：不透明 → 微透 → 半透 → 很透。
氛围
昼夜色调 · 灵气粒子流 · 轻天气（雨 / 雪 / 霞）。「自动」＝全开，但系统开着「减弱动态」时自动降一档（粒子更稀更缓）；想彻底安静点上面这一行切成「静态」或「关闭」。
天气
「自动」按游戏日轮换（现实约 4 分钟一变；霞只出现在晨/暮）；手动指定即固定，便于挨个看。
昼夜
「自动」跟现实时钟（24 小时一循环）：白天亮、黄昏暖、夜里冷；也可手动定格晨 / 昼 / 暮 / 夜。
氛围负载标准
低性能自动降载：帧率不足时先减稀粒子、必要时停天气，恢复后自动升回（无需你操心；窗口被遮挡时不会误判）。
皮肤
四套色板 + 一档「随世界」（按当前世界色系自动跟随，重掷此界即时换）：鎏金 / 朱砂 / 玄墨 / 月白。只换色彩语义，版式与数值一律不动。
GM 控制台Ctrl+Shift+G
开发者工具：自选世界开局 / 重测灵根 / 立即触发一次事件（用于验收各界的专属事件池与灵根池）。
