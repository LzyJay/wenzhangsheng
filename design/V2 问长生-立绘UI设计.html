肆 新旧对比

V1 · 几何小人（现状）

矩形拼装，无服饰无层次；优点是体量轻、远看有轮廓；近看缺乏「修仙感」，与楷体境界名的古典气质断裂。

➜

V2 · 分层矢量立绘（本稿）

仍是纯矢量（Symbol + 渐变），无位图依赖；服饰分 6 层可拆件复用（换装/灵根变体只改色板）；呼吸/摆动/状态演出全部沿用现有事件链。

伍 落地规格 · 交给 MainScene.js

画布与尺寸立绘贴图按 300:640 比例裁切（高 760px，JPEG q84 内嵌）；小窗内显示高 196px（全身约占窗高 61%，紧凑顶/底栏腾出空间），宽自适应；实装将贴图落为 assets/portrait_male.jpg / portrait_female.jpg（@2x），由 Phaser 加载为纹理替代现有 Graphics 拼装。
站姿全身站姿 · 全身完整入画：立绘显示高 196px、margin-top:64px，发冠不贴顶栏、战靴与投影完整露出；顶栏（padding 6/2）与底栏（按钮 30px + 日志 9px）已紧凑化腾出空间。
参考图整图裁切男修原图裁 (52,70)→(626,1295)、女修裁 (105,12)→(658,1190)（避开右下角水印），统一缩放到高 760px；男修提亮 6%、女修 2%；四周暗角晕影（椭圆 mask，中心 50%/40%，向底色 #121119 熔接）让灰底/白底统一成聚光质感；换立绘只需替换 __PIC_MALE__ / __PIC_FEMALE__ 两个 data URI。
呼吸基准轴心 = 丹田 (150, 300)，即 viewBox 高度 47%（对应旧 120 画布的 y90 口径）；幅度 scaleY 0.994 / translateY -1.2px，周期 3.6s ease-in-out。换算公式照旧写进 MainScene 顶部几何常量区。
次级摆动马尾（男）/ 颊发+飘带（女）以发根为轴 rotate ±1.6°，周期 5.2s，与呼吸错拍；渡劫时周期缩至 1.2s 增加紧张感。
图层序（男）背发 → 发带 → 下摆（玄裙→绛红内衬→月白云纹→金线收边）→ 战靴 → 躯干 → 交领 → 朱红大氅 → 肩甲 → 广袖 → 束腰挂坠 → 颈头 → 前发 → 发冠。
图层序（女）背发 → 水蓝披帛（最宽后层）→ 月白主裙 → 侧衩层纱 → 绣鞋 → 躯干 → 广袖 → 腰封垂珠 → 颈头 → 前发颊发 → 发髻银簪。
状态演出五态五色，一眼可辨：常态·玉青（足下薄雾 + 虚线环 26s 缓旋）／ 就绪·鎏金（金雾 + 环加速 9s + 实线环脉冲 + 金粒上升）／ 渡劫·金雷（暖幕压暗 + 左右金黄双雷交替 + 身侧金弧 + 人物压暗）／ 道伤·赤红（降饱和 + 红晕脉冲 + 血烬飘落，filter 实现）／ 飞升·金玉双辉（双色光柱 + 花瓣螺旋 + 光轮 + 上浮）。全部为叠加层，不修改立绘本体。
换装扩展色板即皮肤：男修三色（朱砂/玄墨/鎏金）、女修三色（月白/水蓝/银灰）抽为变量；未来灵根金木水火土变体只换 gRed / gInk / gGold 三组渐变即可。
reduced-motion呼吸/摆动/粒子/雷闪/光轮全部降级为静态帧（本页已内置同款降级演示）。
边界重申窗口形态 420×320、楷体境界名、金 #E8B96A / 玉 #7FD6A8 功能色血统——全部未动；灵玉挂坠把玉绿缝进立绘，作为「人 UI 同源」的细节锚点。
